# InstiFlow – IITM Academic Dashboard

InstiFlow is a comprehensive academic productivity platform designed specifically for students of IIT Madras. The platform helps students efficiently manage their academic schedules, tasks, and daily activities through a centralized and intuitive dashboard.

## Overview

Managing academic commitments, assignments, deadlines, and class schedules can be overwhelming for students. InstiFlow addresses this challenge by providing a personalized workspace that enables students to organize their academic life and improve productivity.

The platform combines timetable management, task tracking, calendar visualization, and daily schedule monitoring into a single seamless experience.

## Key Features

### Timetable Management

* Create and manage personalized academic timetables.
* Organize courses, lecture timings, and weekly schedules.
* Automatically visualize daily and weekly academic plans.

### Smart Dashboard

* View daily class schedules at a glance.
* Track the total number of classes for a given day.
* Access upcoming academic commitments through a centralized dashboard.

### Calendar Integration

* Interactive calendar for schedule visualization.
* Monitor classes, assignments, and events on specific dates.
* Improve planning through structured academic scheduling.

### Task Management

* Create, organize, and track academic tasks.
* Manage assignments, deadlines, and personal goals.
* Monitor pending and completed tasks efficiently.

### Daily Productivity Tracking

* Get a clear overview of daily responsibilities.
* Improve time management and academic planning.
* Reduce scheduling conflicts and missed deadlines.

## Problem Solved

Students often rely on multiple applications to manage schedules, assignments, and academic planning. InstiFlow consolidates these functionalities into a unified platform, reducing complexity and improving overall productivity.

## Design Philosophy

InstiFlow follows a user-centered design approach focused on:

* Simplicity
* Accessibility
* Efficiency
* Intuitive navigation
* Modern user experience

The platform emphasizes minimal cognitive load while ensuring that essential academic information remains easily accessible.
